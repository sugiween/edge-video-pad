# Video Pad

YouTube などブラウザで見ている動画を、マウスだけで操作できる浮かぶボタンです (Microsoft Edge 拡張機能)。

動画の上でマウスを動かすと画面の下にボタンが出て、2.5 秒さわらないと消えます。全画面にしている間も使えます。

| ボタン | 動き |
|---|---|
| ⏯ | 再生 / 一時停止 |
| ← → | 5 秒戻る / 5 秒進む (長押しで連続) |
| ↑ ↓ | 音量を上げる / 下げる (長押しで連続。YouTube では YouTube の音量を 5% ずつ) |
| F | プレーヤーの全画面 (YouTube の F キーと同じ) |
| ⛶ | ブラウザの全画面 (F11 キーと同じ) |

## 入れ方

ストアには出していないので、ダウンロードしたフォルダを Edge に直接読み込みます。

1. このページの緑の「Code」ボタン →「Download ZIP」でダウンロードし、ZIP を展開する
2. Edge のアドレスバーに `edge://extensions` と入れて開く
3. 「開発者モード」をオンにする
4. 「展開して読み込み」を押し、展開したフォルダ (`manifest.json` が入っているフォルダ) を選ぶ
5. すでに開いている動画のタブは再読み込みする

## 新しい版にするとき

ZIP を取り直して同じフォルダに上書きし、`edge://extensions` で Video Pad の「再読み込み」を押します。

## 補足

- どのサイトでも動きますが、ボタンが出るのは画面に動画が見えているときだけです
- ページに埋め込まれた動画 (iframe の中) は対象外です
- 動画を探すためにすべてのサイトのページで動くので、Edge には「すべてのサイトのデータの読み取りと変更」ができる拡張として表示されます。外部との通信はしません
- 保存するのは、ブラウザ全画面にする前の窓の状態だけです (`storage`)
